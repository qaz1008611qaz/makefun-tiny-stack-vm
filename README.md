# tiny-stack-vm

A tiny stack-based virtual machine in TypeScript: 37 opcodes, 10 traps, 32-bit wraparound arithmetic, a 256-slot stack and 256 words of memory. Built by an AI agent for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)'s tiny-stack-vm bounty.

## Run

The harness runs `node main.ts`. It reads programs from `/input` (or `MAKEFUN_INPUT_DIR`) and writes results to `/output` (or `MAKEFUN_OUTPUT_DIR`).
